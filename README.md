## 🍷 ML-Service-Project: Система прогнозирования качества вина
### Описание проекта
Этот проект представляет собой интегрированный сервис на основе машинного обучения (Machine Learning) для прогнозирования качества вина на основе его химических характеристик.
## Business Logic & Billing System
### Unique Value Proposition (UVP)
Проект предоставляет интеллектуальную систему оценки качества вина на основе машинного обучения со следующими преимуществами:
- **Мгновенное прогнозирование (Real-Time Prediction):**
В отличие от традиционных лабораторных тестов, которые могут занимать несколько дней, система обеспечивает мгновенную оценку качества вина.
- **Принятие решений на основе данных:**
Платформа снижает зависимость от человеческой дегустации и предоставляет объективную и стабильную оценку качества.
- **Полная прозрачность и мониторинг:**
Все запросы на прогнозирование отслеживаются в реальном времени с помощью панелей Grafana.
- **Модель Freemium-доступа:**
Каждый новый пользователь получает 100 бесплатных кредитов при регистрации.
- **Система геймификации и лояльности (Gamification & Loyalty System):**
После 5 успешных прогнозов стоимость одного прогноза снижается с 10 до 5 кредитов.

### Логика биллинговой системы
Проект реализует биллинговый механизм на основе кредитов с использованием модели **Pay-as-you-go (оплата по мере использования)**.

* Правила списания кредитов
- Каждое предсказание стоит **10 кредитов**
- После 5 успешных предсказаний стоимость снижается до **5 кредитов**
- Система всегда списывает кредиты в следующем порядке:
  1. Сначала бесплатные кредиты
  2. Затем платные кредиты

*  Пополнение баланса
- Пользователи могут пополнять баланс через:
  `/billing/recharge`
- Курс конвертации:
  - **1 USD = 10 кредитов**

* Система промокодов
Система поддерживает промокоды для маркетинговых кампаний.

**Пример:**
- `WINE2026`
  - Даёт 100 бесплатных кредитов
  - Может быть использован только один раз для каждого пользователя
  - Имеет срок действия и ограничения на использование

* Правила безопасности биллинга
- Один и тот же промокод нельзя использовать повторно одним пользователем
- Просроченные промокоды автоматически отклоняются
- Запрос на предсказание отклоняется при недостаточном балансе
- Списание кредитов происходит только после успешного выполнения предсказания
### API Documentation
- POST `/register` → Создание нового пользователя  
- POST `/token` → Вход в систему (JWT-аутентификация)  
- GET `/me` → Получение информации о пользователе и балансе  
- POST `/predict` → Прогноз качества вина (списывает кредиты)  
- POST `/billing/recharge` → Пополнение баланса кредитами  
- POST `/promo` → Активация промокода
